# TitanicDataCleaning
A beginner-level Python project for cleaning and preprocessing the Titanic dataset. 
🚢 Titanic Data Cleaning Project

📌 Project Overview

This project focuses on cleaning and preprocessing the Titanic passenger dataset using Python and Pandas. The main objective is to identify missing values, handle incomplete data, and prepare the dataset for further analysis and machine learning.

🎯 Objectives

Load the Titanic dataset using Pandas.
Explore the dataset using basic statistical functions.
Identify missing values.
Handle missing values using appropriate techniques.
Prepare the dataset for further analysis.

🔍 Data Cleaning Techniques

1. Data Loading: Loaded the Titanic dataset using Pandas.
2. Data Exploration: Used "head()", "info()", and "describe()" to understand the dataset.
3. Missing Value Detection: Used "isnull().sum()" to identify missing values.
4. Age Imputation: Filled missing age values using the median.
5. Embarked Imputation: Used the mode to fill missing Embarked values.
